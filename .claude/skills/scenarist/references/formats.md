# Шаблони форматів

## A. Reels (20–45 с, «говоряща голова» / кадри + текст / тренд-звук)

Основна структура (див. reels-method.md): **знайоме → аналіз знайомого → нове → пояснення → міст до експертності → куди далі**.
```
[0–2 с] ХУК — широкий вхід зі світу людини + когнітивний розрив (знайоме переконання + суперечність). Текст на екрані ≤ 8 слів. Кадр з дією/емоцією, не статичне «привіт».
[2–6 с] ВПІЗНАВАННЯ — конкретна сцена «ви теж…?» / «я теж так робила»
[6–20 с] ПОВОРОТ — «АЛЕ є нюанс» → аналіз знайомого → неочевидна причина (одна думка). Тут сценарій повертає кредит уваги
[20–30 с] ДОКАЗ — особиста історія / кейс / цифра / контраст до-після
[30–40 с] ВИСНОВОК одним реченням + позиція
[фінал] CTA, що продовжує тему: «детальніше в Highlights "…"», «напиши в Direct слово "…"», «збережи, щоб…»
```
Перший кадр: незвичний ракурс / порушення «експертного» образу / контраст / великий текст в лоб / жест у камеру.
Монтаж: зміна плану кожні 2–3 с; субтитри завжди (більшість дивиться без звуку); акцентне слово капсом/кольором;
джамп-кати на паузах; B-roll на абстрактних словах; фінальний кадр можна закільцювати з першим (повторний перегляд).
Обкладинка: 3–6 слів, суть-обіцянка або провокація.

Типи Reels для чергування:
1. Неочевидна думка («ваш потенціал — причина…»)
2. «Всі — і тут я» / контраст очікування й реальності
3. Розбір фрази клієнта/коментаря
4. Міні-сторі з життя з висновком
5. Пародія / гумор на болі ніші
6. Адресний хук «Вам 34, а ви досі…» → Highlights
7. «Почали за здравіє, закінчили за упокій»: провокація з життя («Секс на пляжі придумали ті, хто ним там не займався») → розвінчання → особистий інсайт → несподіваний міст у продукт
8. Рефреймінг з персонажем: «Приходить Людка з роботи…» → смішна сцена → глибока причина → «якщо ти теж трохи Людка — велкам»
9. Мотивація клієнта як тема: «У тат після дитини особистість залишається. У мам — ні» → продукт як перший вибір «для себе»
10. Стереотип + 3 аргументи: «[найтупіша фраза про професію]» → 3 аргументи, кожен відкриває неочевидне → чому звернутися
11. Абсурдна паралель: «Як фарбується працівниця РАЦСу…», «Як би я пояснила бабі Каті…», «Ребрендинг ларька "У Оксани"»
12. Threads-адаптація: суперечлива тема з Threads → «а в [ніші] так само кажуть, що…» → спільна глибинна думка → висновок
13. Провокуємо і вчимо: «верблюжа лапка» ніші + реальна користь («Макіяж для продавщиці в ларьку… а синій реально в моді, і от як красиво»)
14. Заперечення як тема: «дорого / сама можу / не вірю / навіщо мені» → ролик-відповідь через ситуацію клієнта
15. **Плітка-розслідування (режим Б)**: [суб'єкт] + [різке дієслово/цифра] + [незакритий наслідок] → «що сталося» (скріни новин, спліт-екран) → «і до чого тут маркетинг/[моя ніша]» → «але на мою думку…» → мораль про психологію людей → кодове слово або питання для суперечки. 60–110 с, тільки голос, предмет у руках, щось нове в кадрі кожні 2–4 с
16. **Контраст**: «Бідна людина купить [X]. А багата — [Y]» → чому → що це каже про психологію/ринок
17. **Шокова цифра**: «Щоб [бажане], треба заплатити [цифра]» → чому так дорого → дешевша альтернатива (мій продукт)

## B. Stories-сторителінг (6–12 кадрів)

```
1. Тригер (особиста подія / фраза / зізнання) + привід дивитись далі («зі звуком», «ну шо, розказати?»)
2. Що сталося — сцена, деталі
3. Контекст / як було раніше
4. Поворот: що я зрозуміла / моя позиція
5. Велика проблема, яка стоїть за ситуацією → впізнавання («у вас теж так, коли…»)
6. Чому так відбувається (неочевидна причина)
7. Що змінити / шлях
8. Доказ: кейс, цифри, скрін відгуку
9. Продукт як продовження («і саме це ми робимо на…»), лінк-стікер
10. Взаємодія по темі (питання / слово в Direct / опитування, що продовжує історію)
```
Для кожного кадру вказуй: візуал (селфі-відео, фото в моменті, скрін, колаж), текст на екрані, стікер.

Stories «в моменті»: 3–8 кадрів, короткі підписи з самоіронією, без висновку — це теж ок.

## C. X / Twitter

**Одиночний пост (≤ 280 символів)** — формули:
- Парадокс: «Ваш потенціал — причина, чому ви досі нічого не досягли. Поки можеш стати ким завгодно — стаєш ніким.»
- Зізнання-табу: «Я люблю гроші. І досі соромно казати це вголос. Цікаво чому.»
- Впізнай себе: «Ви втретє переписуєте пост і не публікуєте, бо колеги подумають, що ви "строїте з себе експерта". Знайомо?»
- Спостереження з самоіронією: «багата успішна жизнь: сплю на матраці на клійонці 1,5 роки, зате догляд за шкірою — тищу зелених»
- Чужа фраза + реакція: «Клієнтка: "зроби красівєнько". Я: не все красівєньке — сенсовне.»

**Тред (5–9 постів)** — це сторителінг Stories у тексті:
```
1/ Хук: тригер + обіцянка («…і це змінило, як я беру гроші. Тред 🧵»)
2/ Сцена — що сталося
3/ Як було раніше / що всі думають
4/ «Але є нюанс» — неочевидна причина
5/ Доказ — історія, цифри
6/ Висновок однією фразою (пост, який хочеться ретвітнути)
7/ Що робити (1–3 кроки)
8/ Продукт як продовження / «пишіть в DM слово …» / підписка
```
Метод Reels працює і в X: перший пост = широкий вхід + когнітивний розрив («Турботлива жінка — найбільший абʼюзер у стосунках»),
далі сцена з персонажем, аналіз знайомого, неочевидна причина, міст до експертизи. Пости «очевидна правда» не летять.

Правила X: перше речення працює без контексту; без хештегів або 1; лінк не в першому пості (у відповіді);
відповідайте на коментарі в перші 30–60 хв; цитуйте/відповідайте великим акаунтам у ніші своєю позицією.
Шаблони з режиму Б для X: «[Бренд/біржа/проєкт] just lost its mind» / «[Суб'єкт] з'їхав з глузду» → тред-розслідування зі скрінами
(що сталося → механіка → «але насправді…» → мораль); «Бідний [персонаж] купує X. Багатий — Y»; «Всі сміються з тих, кого розвели — бо впевнені,
що з ними такого не станеться»; CTA: «Reply "[СЛОВО]" — скину повний розбір у DM» або «збережи». Раз на тиждень — фототред
«На цьому фото я ще не знала, що…» (аналог каруселі).
Меми: картинка + 1 рядок, що переносить мем у біль ніші; мем підбирати під емоцію, не під тему (див. `memes.md`).

## D. Threads
Як X, але тепліше й особистіше; «Прочитала в Тредс…» — нормальний тригер. Питання в кінці для дискусії.

## E. Telegram-пост
```
Заголовок-хук жирним (1 рядок)
Сцена/історія (2–4 абзаци по 1–3 рядки)
Поворот + неочевидна думка
Позиція / висновок
М'який CTA (реакція, коментар, лінк, «у закріпі…»)
```
Формати в стилі Пліткарки:
- **Розбір інфоприводу**: що сталося (1 абзац) → чому це працює/провалилось (маркетинг/психологія) → «що забираємо собі» 3–5 пунктами.
- **Заголовок-парадокс**: «[Чеснота] — шлях до [провалу]» → особиста історія → великий контекст/цифри → висновок для читача.
- **Питання → розбір**: пост-питання в коментарі, наступного дня окремий розбір відповідей.
- **Твіст у кінці**: теза застосовується до самої авторки.
- **Кейс**: завдання → бар'єр покупця → офер → результат → принцип, який можна забрати.
Можна довше й інтимніше, ніж в Instagram: «щоденник», голосові-кружечки, опитування. Регулярні рубрики (див. creators.md).

## F. Карусель (7–10 слайдів)
**Варіант Б «фото + плашки»** (найбільше лайків у Борисенко): живі фото без дизайну, на кожному біла текстова плашка 1–3 рядки.
Обкладинка — інтрига з особистої історії: «На цьому фото я ще не знаю, що [подія]. І я втрачу [що]» /
«Нічим у результаті залишається той, хто [теза]. І мені знадобилося [N] років, щоб зрозуміти чому 👉» /
«Сьогодні мені захотілося [несподівана дія]». Далі історія «провал → висновок», останній слайд — мораль + м'який CTA.

**Варіант експертний:**
1 — хук-обкладинка (провокація/обіцянка) · 2 — впізнавання · 3–7 — розкриття, по думці на слайд ·
8 — висновок · 9 — продукт/CTA «збережи / надішли подрузі, яка…».

## G. Офер, назва продукту, лід-магніт (коли треба продати)
- Офер: «[Результат] за [термін] для [ЦА з обставиною]. [Формат + супровід + контроль прогресу]». Перевірка: хоче? вірить? недовго? не складно?
- Назва мовою клієнта, не методу: «Як [перестати/почати] [побутова ситуація], навіть коли [ускладнення]».
- 4 формули назви лід-магніту: число+результат+термін / «як [хороше] без [поганого], навіть якщо [сумнів]» / прикметник+результат / «Х помилок, які заважають…».
- Лід-магніт закриває ясність і **відкриває наступну потребу**; основний продукт — помітно дорожчий.
- Гарантія з ігровою механікою; дефіцит через правило, не таймер.
- Метаповідомлення «скажіть несподіване»: «Ми [чесно визнаємо слабке], зате [реальна перевага]».
- 4 сюжетні лінії для контент-плану: дослідник / «я свій» (жиза) / авторська думка / артефакти (відгуки-історії).
