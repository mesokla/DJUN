# Шаблони форматів

## A. Reels (20–45 с, «говоряща голова» / кадри + текст / тренд-звук)

```
[0–2 с] ХУК — фраза + текст на екрані (≤ 8 слів). Кадр з дією/емоцією, не статичне «привіт».
[2–6 с] ВПІЗНАВАННЯ — конкретна сцена «ви теж…?» / «я теж так робила»
[6–20 с] ПОВОРОТ — «АЛЕ є нюанс» → неочевидна причина (одна думка)
[20–30 с] ДОКАЗ — особиста історія / кейс / цифра / контраст до-після
[30–40 с] ВИСНОВОК одним реченням + позиція
[фінал] CTA, що продовжує тему: «детальніше в Highlights "…"», «напиши в Direct слово "…"», «збережи, щоб…»
```
Монтаж: зміна плану кожні 2–3 с; субтитри завжди (більшість дивиться без звуку); акцентне слово капсом/кольором;
джамп-кати на паузах; B-roll на абстрактних словах; фінальний кадр можна закільцювати з першим (повторний перегляд).
Обкладинка: 3–6 слів, суть-обіцянка або провокація.

Типи Reels для чергування:
1. Неочевидна думка («ваш потенціал — причина…»)
2. «Всі — і тут я» / контраст очікування й реальності
3. Розбір фрази клієнта/коментаря
4. Міні-сторі з життя з висновком
5. Пародія / гумор на болі ніші
6. Адресний хук «Вам 34, а ви досі…» → Highlights

## B. Stories-сторителінг (6–12 кадрів)

```
1. Тригер (особиста подія / фраза / зізнання) + привід дивитись далі («зі звуком», «ну шо, розказати?»)
2. Що сталося — сцена, деталі
3. Контекст / як було раніше
4. Поворот: що я зрозуміла / моя позиція
5. Велика проблема, яка стоїть за ситуацією → впізнавання («у вас теж так, коли…»)
6. Чому так відбувається (неочевидна причина)
7. Що змінити / шлях
8. Доказ: кейс, цифри, скрін відгуку
9. Продукт як продовження («і саме це ми робимо на…»), лінк-стікер
10. Взаємодія по темі (питання / слово в Direct / опитування, що продовжує історію)
```
Для кожного кадру вказуй: візуал (селфі-відео, фото в моменті, скрін, колаж), текст на екрані, стікер.

Stories «в моменті»: 3–8 кадрів, короткі підписи з самоіронією, без висновку — це теж ок.

## C. X / Twitter

**Одиночний пост (≤ 280 символів)** — формули:
- Парадокс: «Ваш потенціал — причина, чому ви досі нічого не досягли. Поки можеш стати ким завгодно — стаєш ніким.»
- Зізнання-табу: «Я люблю гроші. І досі соромно казати це вголос. Цікаво чому.»
- Впізнай себе: «Ви втретє переписуєте пост і не публікуєте, бо колеги подумають, що ви "строїте з себе експерта". Знайомо?»
- Спостереження з самоіронією: «багата успішна жизнь: сплю на матраці на клійонці 1,5 роки, зате догляд за шкірою — тищу зелених»
- Чужа фраза + реакція: «Клієнтка: "зроби красівєнько". Я: не все красівєньке — сенсовне.»

**Тред (5–9 постів)** — це сторителінг Stories у тексті:
```
1/ Хук: тригер + обіцянка («…і це змінило, як я беру гроші. Тред 🧵»)
2/ Сцена — що сталося
3/ Як було раніше / що всі думають
4/ «Але є нюанс» — неочевидна причина
5/ Доказ — історія, цифри
6/ Висновок однією фразою (пост, який хочеться ретвітнути)
7/ Що робити (1–3 кроки)
8/ Продукт як продовження / «пишіть в DM слово …» / підписка
```
Правила X: перше речення працює без контексту; без хештегів або 1; лінк не в першому пості (у відповіді);
відповідайте на коментарі в перші 30–60 хв; цитуйте/відповідайте великим акаунтам у ніші своєю позицією.
Меми: картинка + 1 рядок, що переносить мем у біль ніші (див. `research/memes/`, якщо є).

## D. Threads
Як X, але тепліше й особистіше; «Прочитала в Тредс…» — нормальний тригер. Питання в кінці для дискусії.

## E. Telegram-пост
```
Заголовок-хук жирним (1 рядок)
Сцена/історія (2–4 абзаци по 1–3 рядки)
Поворот + неочевидна думка
Позиція / висновок
М'який CTA (реакція, коментар, лінк, «у закріпі…»)
```
Можна довше й інтимніше, ніж в Instagram: «щоденник», голосові-кружечки, опитування. Регулярні рубрики (див. creators.md).

## F. Карусель (7–10 слайдів)
1 — хук-обкладинка (провокація/обіцянка) · 2 — впізнавання · 3–7 — розкриття, по думці на слайд ·
8 — висновок · 9 — продукт/CTA «збережи / надішли подрузі, яка…».

## Перенесення (одна думка → всі платформи)
| З | В | Як |
|---|---|---|

| Reels | X тред | кожен бит сценарію = пост |
| Stories-сторителінг | Telegram | склеїти кадри в текст, додати заголовок |
| Тред | Карусель | пост = слайд |
